# Responsive Product Pricing Cards

## Overview
A responsive product pricing card website that displays different pricing plans in a clean and modern layout. The page is designed to provide clear pricing information and remain easy to use across different screen sizes.

## Features
- Multiple pricing cards
- Clear pricing and plan details
- Responsive layout for desktop, tablet, and mobile devices
- Clean and user-friendly design
- Highlighted pricing plans
- Call-to-action buttons

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Project Requirements
- Create responsive product pricing cards.
- Use Flexbox and/or Grid for layout.
- Make the design mobile responsive.
- Present pricing information clearly.

## Project Structure

```text
responsive-product-pricing-cards/
├── index.html
└── style.css
```

## How to Run
1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. View the responsive pricing cards.
4. Resize the browser window to check the mobile-responsive layout.

## Design Decision
I chose a clean card-based layout with clear pricing information and call-to-action buttons so users can easily compare different plans. Flexbox and Grid were used to make the layout responsive.

## Learning Outcomes
Through this project, I learned how to:
- Create structured layouts using HTML5.
- Design cards using CSS3.
- Use Flexbox and CSS Grid for responsive layouts.
- Apply media queries for mobile responsiveness.
- Improve user-friendly web design.
